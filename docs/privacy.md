# 用户隐私保护指引（草案 v1.1.0）

本文件用于在微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」中填报，文案可直接粘贴。
最终以公众平台后台的必填项与审核意见为准。

> **同源提示**：本文「用户信息（头像、昵称）」段落与小程序内 `src/pages/privacy/index.vue` 的协议全文、
> POLA-4 后台填报内容必须一字不差。三处任何一处改动，都要同时改另外两处。

## 一、收集与使用的信息

| 信息类型 | 是否收集 | 用途 | 触发时机 |
|---|---|---|---|
| 摄像头 | 是 | 拍摄物品照片，记录箱内物品外观 | 用户在添加/编辑物品页主动点「拍照」 |
| 相册（仅读取） | 是 | 从相册选择物品照片 | 用户主动点「从相册选择」 |
| 剪贴板 | 是 | 复制备份文本、粘贴备份内容以恢复数据 | 用户主动点「导出备份 → 复制」或「恢复备份 → 从剪贴板粘贴」 |
| 用户信息（头像、昵称） | 是（仅本机） | 在「我的」页展示个人资料 | 用户在「我的 → 编辑资料」主动选择头像（`chooseAvatar`）、填写昵称（`nickname` input） |
| 位置、通讯录、麦克风、手机号、微信真实头像昵称 | 否 | 不采集 | — |

说明：

- 照片复制到小程序本地文件目录（`USER_DATA_PATH`）后仅在本机使用，不上传、不联网。
- 备份导出的是文字 JSON，不含照片；备份文本只在本机剪贴板与用户自己保存的位置之间流转。
- 头像、昵称是**用户自行填写与选择的本地资料**，不是账号信息：不取微信真实头像昵称，不登录，
  不上传、不共享、不用于广告或用户画像；独立存 `mover:profile`，不进入 `mover:db`、不进入备份。
- 小程序不登录、不请求微信用户信息、不接入任何第三方统计或广告 SDK。

## 二、后台需勾选/填写的隐私接口

按微信公众平台「用户隐私保护指引」的接口清单，本小程序使用到：

1. `wx.chooseMedia` / `wx.chooseImage` — 选中的照片或视频信息（相册、摄像头）
2. `wx.setClipboardData` / `wx.getClipboardData` — 剪切板
3. **用户信息类目（头像、昵称）** — `chooseAvatar` 与 `nickname` 输入不属于需要弹窗的隐私接口，
   但属于「采集用户信息」，后台需按「用户信息（头像、昵称）」类目如实填写用途与删除途径，
   文案与本文件第一节一致。

未使用：位置、蓝牙、麦克风、通讯录、日历、微信运动、发票、收货地址、相册写入（不保存图片到系统相册）。

## 三、可直接粘贴的指引正文

> 封箱之前是一款本地记录工具，用于登记搬家箱子编号、目标房间与箱内物品。
>
> 1. 为记录物品照片，我们会在你主动操作时使用摄像头拍摄，或读取你选择的相册图片；照片仅保存在你的设备本地，不会上传。
> 2. 为导出和恢复备份，我们会在你主动操作时读取或写入剪贴板中的备份文本；备份只含文字数据，不含照片。
> 3. 我们不收集你的手机号、位置、通讯录等信息，不进行登录、云同步或广告追踪。
> 4. 你在「我的 → 编辑资料」中主动选择的头像会复制到小程序本地文件目录，你填写的昵称保存在微信本地存储，仅用于在本机「我的」页展示个人资料。这些信息不上传、不共享、不用于广告或用户画像；不会随备份导出或恢复。你可以随时在「我的 → 编辑资料」修改，或通过「我的 → 清除本地数据」删除。
> 5. 你可以随时在「我的」中查看数据保存说明、导出备份或清除本地数据；卸载小程序或清理微信数据会删除本地记录、照片、头像与昵称。

## 四、当前账号侧的发现（需要肖祺彦确认）

在微信开发者工具中调用 `wx.getPrivacySetting` 返回：

```json
{
  "needAuthorization": false,
  "privacyContractName": "《物品退休办小程序隐私保护指引》",
  "errMsg": "getPrivacySetting:ok"
}
```

- 该 AppID（`wx634a8ae7205ea24e`）当前关联的隐私指引名称是「物品退休办小程序」，与「封箱之前」不一致，说明这个 AppID 可能沿用了旧小程序主体。
- 提审前需要在公众平台确认小程序名称是否改为「封箱之前」，并按本文件更新隐私指引名称与内容。
- `needAuthorization: false` 表示当前未触发隐私授权弹窗；这不代表摄像头/相册/用户信息项已经声明齐全，仍需在后台逐项核对。

## 五、小程序内的数据说明口径（「我的」页）

「我的」页当前展示：

- 数据概览：`N 次搬家 · M 个箱子 · K 件物品`，灰字注明「含历史搬家」
- 当前占用：`xxx KB`，并提示「照片占空间，卸载或清理微信数据会一起丢失」
- 身份卡：默认头像 + 昵称（空则「未设置昵称」）+「资料只保存在本机」
- 备份：JSON 文本，包含 schema 版本与导出时间，只含文字、不含照片、昵称与头像；恢复前完整校验，失败不覆盖现有数据
- 清除本地数据：两段确认，删除 `mover:db`、`mover:profile`、照片目录与头像目录，不可恢复
- 隐私协议：本地页面渲染全文（含生效日期、联系方式、用户信息声明），不引外链

## 六、隐私授权的前端行为

- 拍照/选图前调用 `wx.requirePrivacyAuthorize`，未同意时由微信弹出官方《小程序隐私保护指引》。
- 用户拒绝后：照片入口给可读提示并停止调用，录入文字与本地数据仍可正常使用，不闪退。
- 备份导出/恢复（剪贴板）同样先过隐私闸门，拒绝时提示，不中断页面。
- H5 与旧基础库没有该 API 时直接放行，不影响本地功能。
