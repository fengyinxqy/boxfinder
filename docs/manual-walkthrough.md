预计 5 分钟；每步只需看结果是否符合「预期」。

| # | 操作 | 预期 |

| 1 | 首页 → 新建搬家「我的第一次搬家」→ 添加 5 个箱子（卧室 / 厨房 / 书房 / 客厅 / 卫生间） | 箱号依次为 1–5 号，删除后新建不复用旧号 |

| 4 | 搬家详情 → 搜索「充电器」 | 结果显示「3 号箱 · 书房」；点击进入 3 号箱 |

| 9 | 拒绝相机/相册授权一次，再点拍照 | 有可读提示，不闪退；再次操作可重新授权 |
