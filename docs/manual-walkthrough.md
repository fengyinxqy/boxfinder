用途：扫码或导入 `dist/build/mp-weixin` 后，按顺序点一遍，确认 v1 六条验收。
预计 5 分钟；每步只需看结果是否符合「预期」。

## 准备

- 用微信开发者工具登录 `wx634a8ae7205ea24e` 的开发者/管理员账号。
- 打开项目 `dist/build/mp-weixin`，或扫本文件对应的预览二维码。
- 首次进入若弹出隐私授权，确认能看到「摄像头」「相册」相关说明。

## 走查步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 首页 → 新建搬家「我的第一次搬家」→ 添加 5 个箱子（卧室 / 厨房 / 书房 / 客厅 / 卫生间） | 箱号依次为 1–5 号，删除后新建不复用旧号 |
| 2 | 进入 3 号箱 → 添加「65W 充电器」→ 点「拍照」或「从相册选择」→ 保存 | 表单出现缩略图；保存后箱内清单显示缩略图 |
| 3 | 回到首页 → 重新进入 3 号箱（或杀掉小程序重进） | 缩略图仍然可见，不是空白或裂图 |
| 4 | 搬家详情 → 搜索「充电器」 | 结果显示「3 号箱 · 书房」；点击进入 3 号箱 |
| 5 | 3 号箱里对充电器点「移箱」→ 选 5 号箱 → 返回搜索重搜「充电器」 | 结果显示「5 号箱 · 卫生间」；5 号箱清单出现该物品 |
| 6 | 1 号箱状态依次点「已封箱 → 已搬运 → 已拆箱」→ 返回搬家详情 | 进度变为 1 / 5；筛选「已拆箱」只剩 1 号箱；再改回「已封箱」进度回 0 / 5 |
| 7 | 数据与说明 → 导出备份 → 复制；清空数据后恢复（或在另一台设备粘贴恢复） | 搬家、箱子、物品数量与归属一致；照片不随备份恢复 |
| 8 | 把备份文本改坏一个字符再恢复 | 提示「备份内容不是有效的 JSON」；原数据不受影响 |
| 9 | 拒绝相机/相册授权一次，再点拍照 | 有可读提示，不闪退；再次操作可重新授权 |
